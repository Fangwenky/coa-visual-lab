# 计算机组成与结构 · 交互式可视化学习工作台 (`coa-visual-lab`)

**在线直接访问（GitHub Pages 静态托管，0 后端）**：https://fangwenky.github.io/coa-visual-lab/

面向《计算机组成原理 / 计算机组成与结构》课程复习与硬件原理理解的**纯前端 0 后端交互式可视化学习网站**。所有硬件实验计算、波形绘制、全文搜索与学习进度存储（`localStorage`）均在浏览器本地完成，无需任何后端服务器或外部字体网络依赖。项目系统梳理课程六大核心模块的全部知识点、公式与经典例题，并内置 **20 个可单步推演、可自定义参数的硬件交互实验台**，同时提供全章核心公式速查表与章节自测题库。

## 使用方法

### 方式一：直接访问在线静态站点（推荐，免安装、0 后端）
浏览器直接打开 GitHub Pages 托管地址即可使用全部 20 个交互硬件实验台：
> https://fangwenky.github.io/coa-visual-lab/

支持通过 URL 哈希直达任意模块（例如 `#m2`、`#m4`、`#m5`、`#formulas`），刷新页面不丢路径。

### 方式二：本地构建离线单文件 HTML（完全断网可用）

项目集成了 `vite-plugin-singlefile`，构建后会将全部 JS、CSS 内联为单个独立 HTML 文件，且不依赖任何外部 CDN 字体：

```bash
git clone git@github.com:Fangwenky/coa-visual-lab.git
cd coa-visual-lab
npm install
npm run build
```

构建完成后，直接双击打开 `dist/index.html` 即可在浏览器中**0 后端、完全离线**运行。

### 方式三：本地开发热更新预览（仅二次开发时使用）

```bash
npm run dev
```

访问终端输出地址（默认 `http://localhost:5173/`）进行实时修改预览；推送到 `main` 分支后，GitHub Actions 会自动重新构建并部署更新到 GitHub Pages。

## 推荐学习路线

1. **先看总览拓扑**：从首页的整机结构图建立“指令如何从主存进入 CPU、经过译码与运算、再与外设交换”的全局视角。
2. **边读精讲边动手做实验**：遇到补码溢出、IEEE 754 转换、Booth 乘除、Cache 抖动、单总线微操作、流水线气泡与旁路、中断屏蔽字软升级等难点时，直接在嵌入式深色实验台里修改参数、单步运行。
3. **自测 + 公式速查收尾**：完成每章末尾的考点自测并打卡，考前使用「公式速查」集中过一遍全部公式与易错对比表。
